# にじたま 工具箱 —— 功能说明

版本 1.8.11

## 一、这个工具做什么

自动重复刷副本。它驱动真实的游戏客户端，和你手动操作完全等价——
战斗全自动，脚本在战斗过程中**不做任何操作**，只在「任務報告書」出现后
点一次「承認する」，然后选「続けて任務へ」回到选关，按设定间隔开下一轮。

---

## 二、左侧四个页面

### 1. 启动游戏

| 卡片 | 说明 |
|---|---|
| 启动游戏 | 用系统 Chrome / Edge 打开游戏，已登录状态直接进 |
| 窗口大小 | 直接在这里选，不用去设置页 |
| 当前运行设置 | 只读展示：窗口大小 · 声音 · 无头/有窗口 |
| 游戏窗口 | 定时检测，绿点表示已连接 |
| 帮助 | 点整张卡片打开内置帮助面板 |

**声音规则**：设置里「启动时打开声音」为开、且不是无头模式时才有声音。
无头模式强制静音。

### 2. 刷本

**运行模式**（点击标题展开/收起，收起后标题显示当前选择）

- **普通**（默认）：你先在【启动游戏】把游戏开好，脚本连接你那个窗口
- **一条龙**：点「开始刷本」后自动开浏览器、进游戏、开刷

**完成后**

- **留在游戏里**：刷完保留窗口，可以直接接着玩（关掉工具箱也不影响）
- **关闭游戏窗口**：刷完自动关掉

**暂停 / 停止**

| 按钮 | 作用 |
|---|---|
| 暂停 | 立刻停手；正在打的那一场由游戏自己打完，停在结算界面；按钮变成「继续」 |
| 停止 | 结束脚本，游戏里那一场照样自己打完 |

暂停不会中断战斗本身，只是不再替你点「承認する」。点「继续」时会先把这场结算掉，再接着刷。战斗还没开始时暂停，就停在编队界面不出阵。

**任务设置**

| 项 | 说明 |
|---|---|
| 副本 | 净化巡历 / 四方山绘卷 / 夏日祭典 / 曜日任務 |
| 话 | 分话的副本才有这一行；列表是游戏里读来的，新的在上 |
| 关卡 | 点一行就勾上，可以勾多关 |
| 刷本计划 | 勾完在下面出现：每关刷几次、顺序怎么走，见下一节 |

**刷本计划（每关刷几次）**

勾上关卡后，列表下面会出现小方块，一个方块就是一关，**两列排、多了往下滚**：

```
(1) 武藏国 江户 火事 [3] x        (2) 信浓国 下诹访 [1] x
(3) 甲斐国 笹子峠  [1] x          (4) ......                2 关 · 共 4 场
```

一屏能看到**两行半**（4 关整 + 下面那行露一半，一眼就知道还有），再多就上下滚。

- **序号**：方块最前面的数字就是刷的顺序
- **次数**：方块里的数字框，直接敲或按上下箭头，1~999（这一关总共刷几次）。
  点一下就**全选**框里的数字，直接敲新的就替换掉了；右键没有菜单
- **x**：取消这一关，上面列表里的勾会一起取消
- **拖动**：按住方块拖到另一个方块上，这两关**直接对调**位置——
  3 拖到 1 上就是 3 变第 1、原来第 1 的变第 3，其余不动（两列都一样）。
  拖到计划区上下边缘会**自己往下/往上滚**，一整排关卡不用先松手再滚
- 右边显示「几关 · 共几场」；**场次就是计划里的总次数**，这一遍跑完就停，
  想接着刷再点一次「开始刷本」
- **顺序模式**在【设置】→「刷本顺序」里切换：
  - 按勾选先后（默认）：先勾哪关就排哪关，可以把两关拖着对调
  - 按列表顺序：顺序固定跟游戏里的关卡排列，这时拖不动
- 取消勾选再重新勾，会排到计划末尾；之前设的次数会保留
- 两轮之间等多久在【运行模式】卡里的「间隔(秒)」，默认 2 秒
- 两轮之间的等待时间在【运行模式】里的「间隔(秒)」，默认 2 秒

**怎么读列表**

关卡不再写死在代码里了，全部从游戏里读：

1. 【刷本】选好副本，点「读取话列表」→ 读到这一副本的所有话
2. 选一话，点「读取关卡」→ 读到这一话里的全部战场
3. 勾上要刷的关卡（一关或多关）→ 点「开始刷本」

- 读列表只点开关卡界面，**不打、不消耗体力**
- 读到的内容存在 `data/config.json`，下次打开不用重读；游戏更新了再点一次就行
- 曜日任務没有「话」这一层，直接点「读取曜日关卡」
- 话和关卡的名字都是游戏里显示的文字（装了汉化就是中文），不用自己对
- 某一话还没有可打的战场（剧情没推过去、或者活动已结束）时，读取会返回空，
  选它开始刷本会直接告诉你原因，不会闷头失败

**曜日任務怎么用**

1. 先到【启动游戏】点「启动」，等游戏画面出来
2. 【刷本】→ 副本选「曜日任務」
3. 点「读取曜日关卡」→ 自动读取今天开放的全部关卡
4. 勾上要刷的关卡 → 点「开始刷本」

- 关卡列表实时读取，**每天 23:00 后过期**，重新读取即可
- **跨天会自动清空**：过了 23:00 进新的一天，上一游戏日读到的关卡列表和勾选会被清掉
  （旧关卡今天点不到，留着只会一直撞「点不动」）。日志里会写一行「游戏日变了……已清空」
- 「读取」只读列表，不消耗体力或道具
- **每天弹窗提醒一次**：启动时如果今天的列表还没读，会问「现在读取 / 稍后再说」，
  只在第一次提醒，不会每次启动都弹
- 未解锁的关卡游戏本身就不显示，列表里出现的都能打
- 只有标题、没有副标题的是**剧情关**（无战斗），会被自动跳过

**装了汉化插件也能用**

游戏里装了汉化脚本（篡改猴）后，关卡列表的标题和副标题会变成中文
（戦場 其の四 → 战场 其之四，地魂男児の生活 → 地魂男儿的生活）。
工具箱会自动适配，**不需要任何设置**：

| 情况 | 处理方式 |
|---|---|
| 标题/副标题被翻译 | 按「标题 + 副标题特征」打分匹配，中日文都认 |
| 副标题写法不同 | 提取**数字和类型**比较（其の四 = 其之四 = 4；戦場 = 战场）|
| 完全对不上 | 按关卡在列表里的**序号**定位（序号和语言无关）|
| 剧情关（无副标题/クリア条件）| 自动跳过，不会当成战斗关 |

主界面、菜单、按钮文字没有被汉化，所以进入游戏的流程不受影响。

### 3. 设置

| 项 | 说明 |
|---|---|
| 窗口大小 | 小窗口 960×540 / 全屏（最大化） |
| 启动时打开声音 | 关闭则浏览器静音启动 |
| 无头模式 | 不显示浏览器窗口，最省资源；会自动静音 |
| 显卡渲染 | 自动（默认，交给 Chrome）/ 强制独显（省 CPU）/ 软件渲染（应急，部分游戏会白屏） |
| 清理浏览器缓存 | 显示当前占用，点「清理」删掉可安全重建的缓存 |

**关于清理缓存**

Chrome 会自己下载离线 AI 模型和语音语言包，可能占几个 GB。
这个功能只删**不影响游戏流畅度**的缓存：

- `OptGuideManifestModel`、`optimization_guide_model_store`（端侧 AI 模型，最大头）
- `SODALanguagePacks`、`SODA`、`WasmTtsEngine`（语音相关）
- `component_crx_cache`（组件下载缓存）
- `Crashpad`、`BrowserMetrics`（崩溃日志、统计）

**故意没放的**：`ShaderCache`、`GrShaderCache`、`GPUPersistentCache`
（显卡着色器缓存）。删掉不会坏，但下次进战斗会有一小段重新编译的卡顿。

**不会动** `Default` 目录——登录状态、游戏存档都在里面。
清理前需要先关掉游戏窗口，否则文件被占用删不掉。

### 4. 日志

实时运行日志，可清空或复制。

- **错误日志**：打开 `data/error.log`，只在程序抛异常时才有内容
- **会话日志**：打开 `data/session.log`，完整操作记录（每一轮点了什么、等了多久），
  游戏卡死时翻这个文件，能看到最后几步在做什么

会话日志每行带时间戳，涨到 512 KB 会自动裁剪，只留最近 3000 行。

## 三、第一次使用

1. 打开工具箱，会弹出帮助面板，看完点「开始使用」
   不想每次都看，就勾选「下次启动不再自动弹出」
2. 【启动游戏】→「启动」→ 登录账号
3. 回到【刷本】，选副本类型和关卡，点「开始刷本」

登录状态保存在程序目录的 `profile` 文件夹，下次不用再登。

## 四、运行时会发生什么

```
进关卡 → 出阵 → 战斗（全程不操作）
   → 任务报告书出现 → 点「承認する」
   → 首次通关会弹「チャプター進行」→ 自动关掉
   → 点「続けて任務へ」→ 回到选关
   → 按设定间隔 → 下一轮
```

- 点「停止」**立即中断**（游戏里那场战斗会自己打完）
- 刷完**不会自动回主页**，停在选关界面
- 切换运行模式或副本类型时，会自动把游戏带回主界面
  （否则游戏停在编队/报告书界面会导致定位失败）
- 关卡点不进去时先重建列表再试；连续两次还点不进去，会自动重载页面自救一次
  （整场刷本只重载一次，不会来回重载）
- 游戏画面本身停了（窗口被最小化或被完全挡住）会直接提示你，不会白重载
- 选中的话里没有可打的战场，会直接说明原因并停手，不再闷头失败四次

## 五、注意事项

- **同一账号不能同时登录**。运行刷本前，别在别的浏览器里开着游戏页面
- 一场战斗约 3 分钟，这是游戏本身的时长
- 道具/资源不足时会检测到提示并**自动停止**
- 界面卡住超过 150 秒，脚本会自动重载恢复
- 启动操作无响应 4 次后，会自动重载游戏再试
- 脚本被强行结束后，游戏可能出现「点什么都没反应」（画面照动、按钮正常，
  但人手点也没用）。重载页面（或重启游戏窗口）就能恢复，见常见问题最后一条

## 七、常见问题

**Q: 打开游戏一片白屏？**
A: 看【设置】→「显卡渲染」是不是被选成了**软件渲染**。这一档用 CPU 模拟显卡，
   这个游戏的 WebGL2 跑不起来，表现就是白屏。改回**自动**再启动。

**Q: 双击没反应？**
A: 可能被 Windows 安全提示拦住，点「更多信息」→「仍要运行」。

**Q: 帮助面板不弹了？**
A: 可能是勾选过「下次启动不再自动弹出」。点【启动游戏】页的「帮助」卡片可以手动打开。
   想恢复自动弹出，把 `data/config.json` 里的 `show_help_on_start` 改成 `true`。

**Q: 游戏画面偶尔整个冻住？**
A: 多半是显卡驱动重置（独显直连 + D3D11 下偶发，事件日志里能看到 `nvlddmkm` Id 153）。
   先确认「显卡渲染」是**自动**（推荐），再观察；如果只在「强制独显」下出现，
   说明就是驱动那条路径的问题。别选「软件渲染」——它会让这个游戏白屏。
   这类问题不会报错，只能靠 `data/session.log` 看最后几步在做什么。

**Q: 切到别的窗口后，游戏就不动了？**
A: 1.6.2 起不会了。早期版本里 Chrome 检测到窗口被完全遮挡，会把页面当成不可见，
   动画帧停止回调，游戏逻辑跟着停。现在启动参数关掉了遮挡检测和定时器节流，
   被别的窗口挡住照样跑。
   但**最小化**窗口还是会停——那是真正的隐藏状态，参数解决不了，别最小化就行。

**Q: 提示「连不上游戏窗口」？**
A: 普通模式/刷新列表都需要先打开游戏。先到【启动游戏】点「启动」。

**Q: 刷新读不到关卡？**
A: 需要游戏已经进入主界面（有出陣按钮那页）。

**Q: 能不能刷别的关？**
A: 现在四个入口都能刷：净化巡历、四方山绘卷、夏日祭典、曜日任務。
   每个入口下面的话和关卡都是从游戏里读来的，不再写死，所以游戏加新话、新活动时
   只要点一次「读取」就能刷到。遠征是派遣功能，没有做自动派遣。

**Q: 游戏里点什么都没反应，按钮看着好好的？**
A: 拖拽只发出了「按下」、没发出「抬起」（脚本被强行结束、连接断掉时会这样），
   游戏就一直等着那次触摸结束，之后所有点击都被当成同一次拖拽吞掉。画面照常在动，
   所以看不出来。人手点也一样没反应，`press()` 这类直接调按钮的办法反而还活着。
   重载页面就能恢复：在游戏窗口按 F5，或者关掉游戏窗口重开。正常退出不会留这个尾巴，
   脚本也会在每轮开始和结束时补一次「抬起」。

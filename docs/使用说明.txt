========================================
  にじたま 工具箱  ——  使用说明
========================================

【运行环境】
  Windows 10 / 11，系统里有 Chrome 或 Edge


【四个页面】
  启动游戏   打开游戏窗口并登录
  刷本       选副本、选话、选关卡、开始/停止
  设置       窗口大小、声音、无头模式、清理缓存
  日志       实时运行日志


【第一次用：先登录】
  1. 左侧点【启动游戏】→ 右边「启动」
  2. 在弹出的浏览器窗口里输入账号密码登录
  3. 进入游戏主界面（有「出陣」大按钮那页）
  4. 回到工具箱，点【刷本】
  注意：第一次使用需要手动刷一次本，加载资源
        登录状态会保存


【能刷什么】
  四个入口：净化巡历、四方山绘卷、夏日祭典、曜日任務。
  前三个分「话」，曜日任務点进去就是当天的关卡。

  关卡不再写死在程序里，全部从游戏里读：

    1. 【刷本】选好副本，点「读取话列表」
    2. 选一话，点「读取关卡」
    3. 关卡会列出来，点一行就勾上（可以勾好几关）
    4. 下面出现「刷本计划」小表：每关刷几次、什么顺序
    5. 点「开始刷本」

  ★ 计划区是小方块：(1) 关卡名 [次数] x —— 序号就是刷的顺序
    两列排，一屏两行半（下面那行露一半，说明还有），再多就上下滚
  ★ 次数：方块里的数字框，直接敲或按上下箭头，1~999（点一下会全选数字，敲新的就换掉）
  ★ 取消：点方块最后的 x（上面列表里的勾会一起去掉）
  ★ 顺序：按住方块拖到另一个方块上，这两关直接对调（3 拖到 1 上就是 3 变第 1、
    原来第 1 的变第 3）；拖到计划区上下边缘会自己滚；想整套顺序跟游戏列表一致，
    去【设置】→「刷本顺序」（切成列表顺序后就拖不动了）
  ★ 场次就是计划里的总次数，跑完这一遍就停；想接着刷再点一次「开始刷本」
  ★ 两轮之间等多久在【运行模式】里的「间隔(秒)」，默认 2 秒
  ★ 读列表只点开关卡界面，不打、不消耗体力
  ★ 读到的内容存在 data/config.json，下次打开直接能用
  ★ 游戏加了新话、新活动，再点一次「读取」就能刷到
  ★ 某一话还没有可打的战场（剧情没推过去/活动已结束）会读成 0 关，
    选它开刷会直接告诉你原因

  曜日任務（每天轮换，每天要重读）
    1. 先在【启动游戏】打开游戏，进入主界面
    2. 【刷本】→ 副本选「曜日任務」
    3. 点「读取曜日关卡」→ 读到今天开放的全部关卡
    4. 勾上要刷的关卡 → 点「开始刷本」

    ★ 每天 23:00 后会过期，重新点一次「读取」即可
    ★ 跨天会自动把上一游戏日的列表和勾选清空（旧关卡今天点不到），
      弹窗提醒时点「现在读取」就是重读一遍
    ★ 工具箱每天会弹一次窗提醒「该刷新了」，可以选今读或稍后
    ★ 只有标题、没有副标题的是剧情关（无战斗），不会出现在列表里

  遠征没做——那是派遣功能，不是刷本。


【装了汉化插件也能用】
  装了汉化脚本后，话名和关卡名会变成中文（戦場 其の四 → 战场 其之四）。
  因为列表是直接从游戏里读的，读到的就是你看到的文字，不需要任何设置。


【运行模式】
  普通     需要先打开游戏，停在主界面，在刷本界面点开始刷本
  一条龙   自动执行设置好的任务


【完成后】
  留在游戏里       字面意思
  关闭游戏窗口     字面意思

【暂停 / 停止】
  暂停   立刻停手；这一场让游戏自己打完，停在结算界面；按钮变成「继续」
  停止   结束脚本，游戏里那一场照样自己打完

  暂停不会中断战斗，只是不再替你点「承認する」。
  点「继续」会先把这场结算掉，再接着刷。

【运行时会怎样】
  · 只在「任務報告書」出现后点一次「承認する」
  · 首次通关会弹「チャプター進行」，脚本会自动关掉
  · 然后点「続けて任務へ」回到选关，按设定间隔开下一轮
  · 点「停止」会立即中断脚本
  · 刷完不会自动回主页，停在选关界面
  · 关卡点了进不去时，会先重建列表；连续两次还不行就重载页面自救一次
  · 游戏画面本身停了（窗口被最小化/被完全挡住）会直接提示你，不会白重载


【设置说明】
  窗口大小       小窗口 960×540 / 全屏
  启动时打开声音  关掉则浏览器静音启动
  无头模式       不显示浏览器窗口（默认静音）
  显卡渲染       自动（推荐）/ 强制独显 / 软件渲染
  刷本顺序       按勾选先后（可 ▲▼ 调）/ 按列表顺序
  清理浏览器缓存  删掉 Chrome 自己下的 AI 模型/语言包/日志


【注意】
  · 同一账号不能同时登录，刷本前别在别的浏览器开着游戏
  · 一场战斗约 3 分钟，是游戏本身的时长
  · 道具/资源不足时会自动检测并停止
  · 脚本被强行结束后，游戏可能出现「点什么都没反应」（画面照动、按钮正常，
    人手点也没用）。在游戏窗口按 F5 重载一次就恢复


【文件夹】
  profile/        登录状态（不要删）
  data/           配置和日志
    config.json     读到的副本/话/关卡、刷本计划、所有设置
    session.log     完整操作记录，游戏卡死时翻这个
    error.log       程序出错时的堆栈
  steps/          出错时的截图
  _internal/      运行库
  使用说明.txt     本文件，可以自己改
  功能说明.md      更详细的功能说明


【源码版预览】
  改代码后不用重新打包：双击项目里的「启动源码版（免打包）」，直接跑 app.py。
  它跑的是源码，界面改动立刻生效，但要求本机装了 Python 和依赖。

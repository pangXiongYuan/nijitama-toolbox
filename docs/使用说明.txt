========================================
  にじたま 工具箱  ——  使用说明
========================================

【运行环境】
  Windows 10 / 11，系统里有 Chrome 或 Edge 


【四个页面】
  启动游戏   打开游戏窗口并登录
  刷本       选副本、选关卡、开始/停止
  设置       窗口大小、声音、无头模式、清理缓存
  日志       实时运行日志


【第一次用：先登录】
  1. 左侧点【启动游戏】→ 右边「启动」
  2. 在弹出的浏览器窗口里输入账号密码登录
  3. 进入游戏主界面（有「出陣」大按钮那页）
  4. 回到工具箱，点【刷本】
注意：第一次使用需要手动刷一次本，加载资源
          登录状态会保存

【能刷什么】

  一、净化巡历（内置 7 关）
      武蔵国 江戸 火事（战场 其之四）
      武蔵国 江戸（战场 其之三）
      甲斐国 笹子峠（战场 其之二）
      信濃国 下諏訪（战场 其之一）
      武蔵国 江戸 高難度（高难度战场 其之一）
      甲斐国 笹子峠 高難度（高难度战场 其之二）
      武蔵国 江戸（素材获得战场）

  二、曜日任務（每天轮换，需要读一次）
      1. 先在【启动游戏】打开游戏，进入主界面
      2. 【刷本】→ 副本类型选「曜日任務」
      3. 点「刷新」→ 自动读取今天开放的全部关卡
      4. 选中一关 → 点「开始刷本」

      ★ 每天 23:00 后会过期，重新点一次「刷新」即可
      ★ 「刷新」只读列表，不消耗体力
      ★ 工具箱每天会弹一次窗提醒「该刷新了」，可以选今读或稍后
      ★ 只有标题、没有副标题的是剧情关（无战斗），不会出现在列表里


【装了汉化插件也能用】
  游戏里装汉化脚本后，关卡名会变成中文（戦場 其の四 → 战场 其之四），
  工具箱会自动适配，不需要任何设置：

  · 先按「标题 + 副标题」匹配，中日文都能认（其の四 = 其之四 = 4）
  · 匹配不上时，按关卡在列表里的「序号」定位，序号和语言无关
  · 剧情关（副标题是「クリア条件」或没有副标题）会自动跳过


【运行模式】
  普通     需要先打开游戏，停在在主界面，在刷本界面点开始刷本
  一条龙   自动执行设置好的任务


【完成后】
  留在游戏里       字面意思
 关闭游戏窗口   字面意思

【暂停 / 停止】
  暂停   立刻停手；这一场让游戏自己打完，停在结算界面；按钮变成「继续」
  停止   结束脚本，游戏里那一场照样自己打完

  暂停不会中断战斗，只是不再替你点「承認する」。
  点「继续」会先把这场结算掉，再接着刷。

【运行时会怎样】
  · 只在「任務報告書」出现后点一次「承認する」
  · 首次通关会弹「チャプター進行」，脚本会自动关掉
  · 然后点「続けて任務へ」回到选关，按设定间隔开下一轮
  · 点「停止」会立即中断脚本
  · 刷完不会自动回主页，停在选关界面


【设置说明】
  窗口大小       小窗口 960×540 / 全屏
  启动时打开声音  关掉则浏览器静音启动
  无头模式       不显示浏览器窗口（默认静音）
  显卡渲染       用 GPU 渲染
  清理浏览器缓存  删掉 Chrome 自己下的 AI 模型/语言包/日志


【注意】
  · 同一账号不能同时登录，刷本前别在别的浏览器开着游戏
  · 一场战斗约 3 分钟，是游戏本身的时长
  · 道具/资源不足时会自动检测并停止


【文件夹】
  profile/        登录状态（不要删）
  data/           配置和日志
  _internal/      运行库
  使用说明.txt     本文件，可以自己改
  功能说明.txt     更详细的功能说明
